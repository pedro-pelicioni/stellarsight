## The transactions

104 rows: 5 setup + 3 cleanup + **96 settled x402 payments**. Dates are each transaction's
ledger `created_at` (UTC) as reported by Horizon.

Every payment here was generated by this repository — there is no third-party traffic yet,
and the rows say which script produced each one. Rows prefixed **`load:`** came from
`npm run evidence:batch`, a serial script paying our own seller: they are breadth of
settlement, never evidence of demand. The full label map is
[`docs/status/provenance.json`](./status/provenance.json), and
[EVIDENCE.md](./EVIDENCE.md) aggregates it.

Rows marked **via hosted stack** settled end to end through the public deployment at
stellarsight.xyz: discovery, the 402 challenge, payment verification, settlement and
durable cataloging all ran on the hosted facilitator, not on localhost.

Rows marked **conformance** were produced by `npm run verify:conformance`, which drives an
**unmodified `@x402/fetch` client** — `wrapFetchWithPayment`, no STELLARSIGHT code on the path —
through the whole 402 → sign → settle → 200 loop against `apps/seller`.
